How it works

A tile joins its six edges in three pairs, so the curves always meet across shared edges and the board is a set of closed loops, each in its own color. Every closed curve counts, even a small circle around a single corner: it is three tiles' arcs closing up. Flipping a tile changes the loop count by −2 if its three curves lie on three different loops (they merge), 0 if on two (they swap territory), or +2 if on one (it splits). It is never an odd number, so you can never merge just two loops, and a board with n loops needs at least (n−1)/2 flips.

Best is the fewest flips that can solve the board you were dealt, and it is exact: there are 1,848,868 single-loop tilings of this board, and best is the number of tiles that differ from the nearest one. Merging whenever you can is usually right but not always: sometimes the only way to match best is a flip that leaves the count alone, and taking the obvious merge costs you two flips later.

Puzzle boards come from a library found by computer search: each is hard for its loop count, and from 5 loops up the obvious move — the nearest merge, or the shortest push toward one — is wrong. (With 3 loops it never is: the shortest push to a merge is always right, so 3-loop puzzles are just long.) Practice boards are computed fresh. Under Puzzle, at least sets the fewest flips a puzzle may need. Reset puts back the board you were dealt for another try.

Solution rings every hexagon still to flip for one shortest way to a single loop, redrawn after every flip, and marks what each flip would do right now. A bar is a push: the curve on one side of it changes partner. Arrows pointing in are a merge, three loops pulled into one; arrows pointing out are a split. Splits belong later: play the others first and they turn into pushes or merges.

Hint rings a cell on some shortest path from where you are now, preferring one that merges loops and never one that splits. Every flip moves you exactly one flip closer to a single loop, or one further.

The table of every solution comes from a small file beside this page and is kept in the browser for next time. If that file cannot be loaded, the page builds the table itself, which takes about ten seconds.
